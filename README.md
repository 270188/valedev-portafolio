# ValeDev — Portafolio

Sitio de portafolio creado con **Vite + TypeScript**.

## Requisitos
- Node.js 20 o superior
- npm

## Ejecutar en tu computadora
```bash
npm install
npm run dev
```
Vite mostrará una dirección local para previsualizar la página.

## Crear la versión lista para publicar
```bash
npm run build
```
El sitio compilado se genera en la carpeta `dist/`.

## Publicar
Puedes subir este proyecto a GitHub y conectarlo a Vercel o Render.
- Build command: `npm run build`
- Output directory: `dist`
